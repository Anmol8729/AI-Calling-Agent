# Clarivo backend dependencies — EXACT pins.
#
# Previously every line used `>=`, which meant two builds of the same commit could
# install different code. A breaking minor release (or a compromised one) would land
# straight in production with no change on our side, and a failure would be
# impossible to reproduce locally. These versions are the ones the application is
# actually verified against.
#
# Upgrading: bump one line, run `pytest backend/tests`, start the app, and check the
# startup log. Do not bump several at once — it makes a regression hard to attribute.
#
# Removed as unused (verified: zero imports anywhere in backend/):
#   celery, apscheduler  - background work runs as asyncio tasks elected by
#                          backend/services/job_lock.py, not a task queue
#   loguru               - the codebase uses the standard `logging` module
#   openai               - the backend's LLM modules were deleted with the legacy
#                          /media-stream pipeline; the voice agent has its own venv
#   razorpay             - backend/services/razorpay_client.py calls the REST API
#                          with httpx and verifies signatures with hmac directly

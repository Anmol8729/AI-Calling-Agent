Cost Reduction Plan

Version 2 — rebuilt on verified provider rates and measured live calls

Prepared for: Engineering & Founders

Status: Phase 1 shipped and verified. Phase 2 pending deployment.

Exchange rate: $1 = ₹96 (verified 27 Jul 2026)

Headline. Cost per 3-minute call has been cut from ₹12.86 to ₹8.40 (−35%), already deployed and verified on live calls. Gross margin on the Starter plan rises from 59% to 68%, and break-even drops from 128 to ~108 customers. The remaining work is not a cost problem — it is a hosting problem.
What changed since v1. Three numbers in v1 were wrong and are corrected here: TTS was priced at $0.05/1k characters (actual: $0.06), the LLM was costed at ₹1.50/call (actual today: ₹0 on Gemini's free tier), and a TTS model switch was claimed to halve cost (it saves nothing — all Turbo models bill at one rate).

4. What is left is a hosting problem, not a code problem

After the changes above, every remaining complaint traced to network distance and jitter from running the agent on a home connection. Measured TCP-443 handshake times from the current machine:

ServiceMinAvgMaxEffect on calls
Gemini45ms287ms1,064ms10s timeouts ⇒ 13.4s replies
Deepgram301ms378ms675msSTT socket dropped mid-call (1006)
MiniMax68ms138ms433ms0.6s gap between sentences = audible cut
LiveKit75ms139ms291ms8.5-minute total outage observed
The 8.5-minute outage matters commercially. While the worker was disconnected, LiveKit had nowhere to send calls — callers heard ringing and hung up. Then the queued dispatches arrived at once and two sessions ran in the same process, which is what "the audio is breaking up" actually was.

Fix: one Linux VM in an India region

ProblemToday (home)On the VM
Gemini round trip45–1,064ms (23× jitter)~10–30ms, stable
Reply latency2.4–13.4starget < 1.5s
Audio gapsevery replyexpected to disappear
Context fetch per call~1.9s~50ms (Supabase is in Mumbai)
Windows RtcError panicworker recycled every callgone ⇒ warm worker
Two clients at onceuntested / breaksworks (AGENT_RECYCLE_AFTER_CALL=0)
ngrok as webhook URLunstable, a launch blockerreal domain + HTTPS

Constraints: x86_64 (the LiveKit noise-cancellation library has no arm64 build), 2 vCPU minimum (real-time audio), Ubuntu 24.04, Mumbai/Bangalore. Full runbook in docs/DEPLOYMENT.md.
